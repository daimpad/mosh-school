Startseite als Kachel-Muster

Der Hero-Look aus dem Bildvergleich (Variante A, „Nebel") — hier nicht mehr als eine große Fläche oben, sondern als Containerelement, aus dem sich die ganze Startseite baut. Die Frage dieses Mockups ist nicht „schön oder nicht", sondern: wann trägt eine Kachel ein Bild und wann nicht — und lässt sich daraus ein Muster machen, das man beim Scrollen versteht.

Alles hier ist zum Spielen: Rhythmus umschalten, Regler ziehen, Bild wechseln, Thema kippen. Es ist eine reine Mockup-Datei — in der App ist nichts davon verdrahtet.

Das Muster in einem Satz

Das Bild ist keine Dekoration, sondern ein Signal für die Art des Ziels. Je weiter unten auf der Seite, desto funktionaler der Bereich — und desto weniger Bild. Wer die Seite zum zweiten Mal sieht, findet Werkzeuge schneller, weil sie anders aussehen als Orte.

  1. Marke — ein Bild, groß. Der einzige Ort, an dem Atmosphäre allein zählt.
  2. Welten (Instrumente, Genres) — Bild. Bereiche, in die man eintaucht und die einen eigenen Klang haben; das Bild trägt hier Bedeutung.
  3. Wege (Kompetenz, Themen, Individual, Training) — nur Motiv, kein Foto. Struktur statt Stimmung: hier entscheidet man, nicht man stöbert.
  4. Werkzeuge — flach, nur Icon. Werkzeuge werden bedient und wiedergefunden; ein Hintergrund würde das Icon nur schwerer erkennbar machen.
  5. Verweise — Zeile mit Icon. Alles, was woanders hinführt.

Was beim Verkleinern auffiel

Der Hero-Look überträgt sich nicht unverändert auf Kachelgröße. Die Weichzeichnung ist inzwischen ganz raus — was als Textur hinter einem großen Hero funktionierte, war über zehn Kacheln verteilt nicht mehr zu erkennen; jetzt sind die Fotos scharf. Geblieben sind zwei Dinge: Das Motiv tritt zurück, wo ein Foto liegt (sonst kreuzen sich zwei Zeichnungen), und die Lesbarkeit trägt ein Rückhalt direkt hinter dem Text statt eines flächigen Scrims — ein Scrim, der für die kleine Augenbraue im hellen Thema stark genug wäre, deckt das halbe Foto zu. Der Themenwechsel zeigt es.

CSS zum Übernehmen 
/* So steht es in css/app.css — die Stellschrauben an einer Stelle. */
:root {
  --bild-weich: 0px;        /* 0 = scharf */
  --bild-deckkraft: .8;     /* wie deutlich das Foto durchkommt */
  --bild-saettigung: 1;     /* 1 = Originalfarben, 0 = Graustufen */
  --bild-zoom: 1.02;        /* Überzoom braucht es nur bei Weichzeichnung */
}

/* Die Sättigung ist themenabhängig: Das helle Thema zeigt die Fotos in
   Graustufen (weisses Blatt, schwarze Tinte). Gesetzt im Themenblock am Ende
   von css/app.css — hier steht nur der dunkle Ausgangswert. */
:root[data-theme='hell'] { --bild-saettigung: 0; }

.genre-landing-bg {
  position: absolute; inset: 0; pointer-events: none;
  background-position: center; background-size: cover; background-repeat: no-repeat;
  filter: blur(calc(var(--bild-weich) * var(--blur-faktor, 1))) saturate(var(--bild-saettigung));
  opacity: var(--bild-deckkraft);
  transform: scale(var(--bild-zoom));
}

/* Motiv zurücknehmen, WO ein Foto liegt — sonst kreuzen sich zwei Zeichnungen. */
.genre-landing-bg ~ .genre-landing-bild { opacity: .1; }

/* Weichzeichnung an die Kachelgröße koppeln (greift erst wieder, wenn
   --bild-weich > 0 ist). */
.bildkachel { --blur-faktor: .68; }

/* Lesbarkeit trägt nicht der flächige Scrim, sondern ein Rückhalt direkt hinter
   dem Text: Er wächst mit der Textlänge mit und lässt das Foto darüber frei.
   Oben weit über den Inhalt hinaus, sonst säße die kleine Augenbraue im
   Ausblendbereich. */
.bildkachel-scrim {
  position: absolute; inset: 0; pointer-events: none; opacity: .8;
  background:
    linear-gradient(to top, var(--flaeche) 8%, rgba(0,0,0,0) 72%),
    radial-gradient(120% 100% at 8% 118%, var(--flaeche) 0%, rgba(0,0,0,0) 55%);
}
.bildkachel-inhalt::before {
  content: ''; position: absolute; inset: -1.5rem -1.05rem -1rem; z-index: -1;
  pointer-events: none; opacity: .9;
  background: linear-gradient(to top, var(--flaeche) 84%, rgba(0,0,0,0) 100%);
}
